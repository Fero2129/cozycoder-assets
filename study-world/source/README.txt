Source code of the Study World Anki add-on (AGPL-3.0, see ../LICENSE).
- anki-addon/lernwelt: the Python add-on
- anki-addon/web, apps/web/src, packages/core/src: the user interface (React + Vite)
Images (books, themes, library) are in the web/ folder of study-world.ankiaddon.
Build: cd anki-addon && npm install && npm run build
